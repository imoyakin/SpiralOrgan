# Release Wrapup

## Purpose

Land work safely and leave a clean handoff.

## Checklist

1. Run relevant tests/lints/builds for changed areas.
2. Ensure working tree is clean and changes are committed.
3. Sync and push:
   - `git pull --rebase`
   - `bd sync`
   - `git push`
   - `git status` shows up-to-date
4. Record a short handoff summary (what changed + next steps).
